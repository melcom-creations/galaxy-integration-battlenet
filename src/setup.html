First time using the plugin? Follow steps 1-3 below to create or use your personal Blizzard API client and sign in.

Your Client ID and Client Secret are already saved. You do not need to enter them again or create a new API client.
You need a free personal Blizzard API client. If you already have one, reuse it.

Open this address in your regular browser (Firefox, Chrome, or Edge) and sign in with your Battle.net account:

This address returns the login to your own computer. No external callback website is needed. The plugin cannot check or change the address saved in Blizzard's portal.

If the address is already saved and working, leave it unchanged and continue.

3
Continue to Battle.net

Next, sign in on Blizzard's login page. If Blizzard rejects the callback address, close that login window, correct the portal entry, wait up to 10 minutes, and connect again.

This guide appears before each new sign-in, including when you reconnect. It does not interrupt an existing valid Galaxy connection.
The plugin saves your OAuth configuration automatically outside the plugin folder. On Windows, it is protected for your Windows account. Keep your Client Secret private.
